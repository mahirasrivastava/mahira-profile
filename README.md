# Mahira Srivastava — Personal Profile Page

My personal portfolio page, built with plain **HTML and CSS** (no JavaScript, no frameworks).

## Sections
- About
- Education
- Experience
- Projects
- Skills
- Achievements
- Interests
- Contact

## Run locally
Open `index.html` in any browser.

## Deploy
Works as-is on GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**.

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css` | All styling, including the CSS-only mobile menu |
| `profile.jpg` | Profile photo |
